socket(int domain, int type, int protocole) : crée un socket et retourne un descripteur de fichier (un entier) qui représente ce socket. Les paramètres sont :
- domain : le domaine de communication (AF_INET pour IPv4, AF_INET6 pour IPv4, AF_UNIX pour les sockets locaux, etc.).
- type : le type de socket (SOCK_STREAM pour TCP, SOCK_DGRAM pour UDP, etc.).
- protocole : le protocole à utiliser (0 pour choisir automatiquement le protocole approprié en fonction du type de socket).

bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen) : associe le socket identifié par sockfd à une adresse réseau spécifiée par addr. Cela permet au socket d'écouter les connexions entrantes sur cette adresse.

listen(int sockfd, int backlog) : met le socket identifié par sockfd en mode écoute pour les connexions entrantes. Le paramètre backlog spécifie le nombre maximum de connexions en attente que le système peut maintenir.
- sockfd : le descripteur de fichier du socket à mettre en écoute.
- backlog : le nombre maximum de connexions en attente que le système peut maintenir.


struct sockaddr_in address; : structure qui contient les informations nécessaires pour établir une connexion réseau (adresse IP et port).
sin_family = AF_INET;

« Je veux utiliser le protocole IPv4 ».

sin_addr.s_addr = INADDR_ANY;

« Je veux écouter sur toutes les interfaces réseau disponibles de la machine » (équivalent à 0.0.0.0, pour accepter les connexions locales et externes).

sin_port = htons(6667);

« Je veux écouter sur le port 6667 » (le port IRC standard, converti au format réseau avec htons).

htons: signifie Host To Network Short.
- Il prend le numéro de port (sur 2 octets, d'où le Short) et le retourne dans le sens exact exigé par le réseau pour que n'importe quelle machine puisse le comprendre.

recv(int sockfd, void *buf, size_t len, int flags):
- Reçoit des données depuis le socket identifié par sockfd et les stocke dans le tampon buffer. La fonction retourne le nombre d'octets reçus ou -1 en cas d'erreur.

accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen):
- Accepte une connexion entrante sur le socket identifié par sockfd. La fonction retourne un nouveau descripteur de fichier pour la connexion acceptée, ou -1 en cas d'erreur
Server(port)
└── initialise _buffers, _pollfds, _server_fd = -1, _port, _addrlen

disconnectClient(index)   ← méthode unique de déconnexion
├── client_fd = _pollfds[index].fd
├── log "Client disconnected"
├── _buffers.erase(client_fd)        → supprime son buffer de lecture
├── close(client_fd)
└── _pollfds.erase(index)            → retire de la liste surveillée par poll
    (l'appelant doit faire i-- ensuite)

initserver()   ← préparation du socket d'écoute
├── 1. socket(AF_INET, SOCK_STREAM, 0)
├── 2. setsockopt(SO_REUSEADDR)
├── 3. fcntl(F_SETFL, O_NONBLOCK)
├── 4. sockaddr_in + memset              → IPv4, INADDR_ANY, htons(port)
├── 5. bind()
└── 6. listen(SOMAXCONN)

serverStart()
│
├── 1. PHASE D'INITIALISATION
│   └── _pollfds[0] = socket serveur (events = POLLIN)
│
└── 2. BOUCLE PRINCIPALE while(1)
    │
    ├── A. poll(&_pollfds[0], _pollfds.size(), -1)
    │   └── activity < 0 → message → exit
    │
    └── B. for chaque fd (index i)
        │
        ├── B1. Erreur ? (i > 0 && revents & (POLLHUP | POLLERR | POLLNVAL))
        │   └── OUI → disconnectClient(i) → i-- → continue
        │
        └── B2. Données ? (revents & POLLIN)
            │
            ├── CAS 1 : fd == _server_fd → NOUVELLE CONNEXION
            │   ├── accept()                      → échec : continue
            │   ├── fcntl(F_SETFL, O_NONBLOCK)    → échec : close + continue
            │   ├── push_back dans _pollfds (POLLIN)
            │   ├── _buffers[client_fd] = ""      → buffer de lecture vide
            │   └── log "New client connected"
            │
            └── CAS 2 : fd == client → DONNÉES D'UN CLIENT
                └── recv(client_fd, buffer)
                    ├── bytesRead < 0  → continue (sans errno)
                    ├── bytesRead == 0 → disconnectClient(i) → i--
                    └── bytesRead > 0
                        ├── _buffers[fd].append(buffer, bytesRead)
                        └── while (find('\n') != npos)
                            ├── line = substr(0, pos)
                            ├── erase(0, pos + 1) du buffer
                            ├── retire le '\r' final si présent
                            └── log "Command received" (→ plus tard handleCommand(fd, line))
